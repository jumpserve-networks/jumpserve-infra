# Autonomous repair release

This release adds durable operational repair to the existing autonomous claim controller. It retains the original claim, source versions, provider and experiment identities, prompts, failures, commitments and deadline. Repair completion sends an implementation through fresh scientific reviews; it does not change an untested or inconclusive finding into a conclusive result.

The private `research_autonomy_repairs` and append-only `research_autonomy_repair_events` tables hold original incident snapshots and versioned transitions. Public queue reads use the existing bounded, redacted backend projections. Anonymous SQL access and browser writes remain denied.

The native builder receives hash-verified diagnosis records and original failure excerpts. Its experiment changes must pass incident-bound software tests in the pinned, network-free validation image. These tests are model authored and are not independent scientific validation. Unknown provider outcomes remain fenced; repair cannot create replacement calls, extend authorization, refund commitments or bypass unavailable apparatus.
