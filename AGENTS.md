# Repository guidance

Use Context7 for library/API documentation and configuration work. Prefer
connected tools and ordinary local checks; preserve unrelated local changes.

The user authorized the **Platform Development Supervisor OpenClaw** to merge
and deploy qualified improvements across the three JumpServe repositories after
initial activation. Its immutable Supabase authorization, fixed checks, protected
exact GitHub revisions, scoped AWS roles, limits and owner controls govern that
service. Do not expand its authority, overwrite evidence or weaken scientific
criteria to obtain a passing release. Preserve original uncertain outcomes and
reconcile their identities before dispatching replacement actions.

Keep ordinary interactive editing local unless the user explicitly requests
deployment of the current changes. The supervisor's standing authority does not
grant unrelated sessions blanket deployment permission. Follow
`docs/platform-supervisor-v1.md` for initial activation and release scope.
